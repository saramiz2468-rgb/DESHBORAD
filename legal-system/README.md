# מערכת ניהול תיקים

אתר לניהול תיקים משפטיים: תיקים, תביעות, פסקי דין, עיקולים, סגירות חשבון, משימות, מכתבי התראה, הסכמים ושונות, עם מנוע אוטומציה למועדים.

## איך פותחים

פותחים את `index.html` בדפדפן (Chrome / Edge / Safari). אין צורך בהתקנה.
אם GitHub Pages מופעל במאגר, הכתובת היא:
`https://saramiz2468-rgb.github.io/DESHBORAD/legal-system/`

## איפה נשמרים הנתונים

לאתר יש שני מצבים, לפי הקובץ `config.js`:

**מצב ענן משותף (מומלץ לצוות)** – כשב-`config.js` יש כתובת פרויקט ומפתח anon של Supabase:
- כל עובדת נכנסת עם מייל וסיסמה, וכולן רואות ומעדכנות את אותם נתונים בזמן אמת, מכל מחשב וטלפון.
- שינויים שנעשים בו-זמנית ממכשירים שונים מתמזגים ולא דורסים זה את זה.
- כל שמירה נרשמת גם בטבלת היסטוריה בענן (200 הגרסאות האחרונות לכל חלק), לשחזור במקרה הצורך.
- העדפות תצוגה (עמוד פתוח, לשונית, סינון) נשארות לכל מכשיר בנפרד.

**מצב מקומי** – כש-`config.js` ריק: הנתונים נשמרים רק בדפדפן של כל מכשיר. להעברה בין מכשירים: "ייצוא גיבוי" ו"ייבוא נתונים".

המאגר ציבורי, לכן **אין להעלות למאגר קבצי נתונים עם שמות לקוחות**. מפתח ה-anon בטוח לשמירה במאגר כי הגישה מוגנת בהתחברות; מפתח ה-service_role לעולם לא נשמר במאגר.

## הקמת הענן (פעם אחת)

1. פותחים חשבון ופרויקט חינמי ב-supabase.com.
2. ב-SQL Editor מדביקים את כל התוכן של `supabase-setup.sql` ולוחצים Run.
3. ב-Authentication: מכבים הרשמה עצמית (Allow new users to sign up) ומוסיפים משתמש לכל עובדת (Add user → Create new user, עם Auto Confirm).
4. מעתיקים את Project URL ואת מפתח ה-anon public ל-`config.js`.
5. אחרי העלאה, נכנסים פעם אחת ומייבאים את קובץ הנתונים. מכאן כל הצוות רואה אותם.

## ייבוא נתונים

"ייבוא נתונים" מקבל שני סוגי קבצים:
1. קובץ גיבוי שיוצא מהמערכת (משחזר את כל המצב).
2. קובץ נתונים בפורמט `{ "db": { "claims": [...], "closures": [...] } }` (מוסיף שורות לטבלאות, בלי כפילויות לפי מזהה).

## אוטומציות עיקריות

- מכתב התראה: ספירה מתאריך המסירה (הוצל״פ 30 יום, בימ״ש 21 יום). בתום המועד: כפתור פתיחת תיק עם מספר תיק ועו״ד, והתיק נרשם בטבלת תיקים.
- טבלת תיקים: סטטוס "תביעה" מעביר לתביעות, "הסכם" מעביר להסכמים. הסטטוס העדכני מתעדכן אוטומטית מכל הטבלאות.
- תביעת בימ״ש שהוגשה: ממתינה למסירה אישית (עם משימה אוטומטית). הקלדת תאריך מסירה מעבירה לפסקי דין.
- פסקי דין: 60 יום ממסירה → בקשה בנט → פסק דין → פסיקתא במסירה → 30 יום → פתיחת הוצל״פ → מסמכים לקובי. יציאה מהמסלול: כתב הגנה / חדל״פ.
- הסכמים: סכום חוב, חודש ראשון ואחרון → תשלום חודשי, שולם, פיגורים. תשלום חסר → שאלה למכתב הפרה. שולם במלואו → שאלה להכנת טופס סגירה.
- מועד שחל בשבת נדחה ליום א׳.
- דוח מרוכז להדפסה: כל מה שבבדיקה, לפי אחראית ונושא.

הפניות לסעיפי חוק במסך "מנוע אוטומציה" מסומנות "לאימות משפטי" ויש לאמת אותן מול עו״ד.
