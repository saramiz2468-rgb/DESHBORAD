# TAHARA

יומן אישי למעקב מחזור, טהרת המשפחה, ימי הפלגה ופוריות. אפליקציית Web (PWA) בעברית, שעובדת במלואה במכשיר עצמו.

## פרטיות
- כל המידע נשמר רק בדפדפן של המכשיר (localStorage). אין שרת, אין צד שלישי, אין פונטים חיצוניים ואין כלי מעקב.
- נעילה בקוד אישי: כשהיא פעילה, הנתונים מוצפנים ב-AES-256-GCM, עם מפתח שנגזר מהקוד (PBKDF2).
- ייצוא ל-Excel ול-PDF, גיבוי ושחזור (JSON), ומחיקת כל הנתונים.

## הפעלה
האפליקציה צריכה לרוץ מכתובת https (למשל GitHub Pages), כדי שתהיה אפשרות להתקין אותה במסך הבית ולהשתמש בה בלי חיבור לרשת.
באייפון: Safari ← שיתוף ← "הוספה למסך הבית".

להרצה מקומית: `python3 -m http.server` בתיקייה הזו, ואז לפתוח את הכתובת http://localhost:8000.

## קבצים
- `engine.js` – מנוע החישובים: תאריכים עבריים, זריחה ושקיעה, עונות והפלגה, ביוץ ושבעה נקיים.
- `app.js` – ממשק, שמירה, הצפנה, ייצוא ותזכורות.
- `styles.css`, `index.html`, `manifest.webmanifest`, `sw.js`, `icons/`.

> החישובים ההלכתיים הם כלי עזר טכני בלבד ואינם פסק הלכה. התחזיות הרפואיות הן הערכה בלבד.
