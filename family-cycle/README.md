# המעקב המשפחתי שלי

אפליקציית Web (PWA) בעברית, שבה אמא מנהלת מעקב מחזור נפרד לכל אחת מהבנות: פרופילים, לוח שנה, היסטוריה, גרפים ותחזית משוערת.
האפליקציה עובדת כמו TAHARA: היא פועלת במלואה במכשיר עצמו, בלי הרשמה, בלי אימייל ובלי שרת.

## פרטיות
- כל המידע נשמר רק בדפדפן של המכשיר (localStorage). אין שרת, אין צד שלישי, אין פונטים חיצוניים ואין כלי מעקב.
- **נעילה בקוד אישי** (מוצעת כבר בפתיחה הראשונה): כשהיא פעילה, כל הנתונים מוצפנים ב-AES-256-GCM, עם מפתח שנגזר מהקוד (PBKDF2, ‏250,000 סבבים). בלי הקוד אי אפשר לקרוא אותם.
- נעילה אוטומטית כשהאפליקציה עוברת לרקע (מיד, אחרי דקה, 5 או 15 דקות), וכפתור נעילה ידני בסרגל העליון.
- גיבוי לקובץ ושחזור ממנו (אם הנעילה פעילה, גם הגיבוי מוצפן בקוד). מחיקת כל הנתונים מההגדרות.
- "שכחתי את הקוד": בלי הקוד אי אפשר לפענח. אפשר לאפס את האפליקציה ולשחזר מקובץ גיבוי.

> הנתונים קיימים רק במכשיר שבו הוזנו. ניקוי נתוני הגלישה מוחק אותם, לכן כדאי לגבות מדי פעם (תפריט ← גיבוי לקובץ). כדי להעביר נתונים למכשיר אחר: גיבוי במכשיר אחד ושחזור במכשיר השני.

## הפעלה
האפליקציה צריכה לרוץ מכתובת https (למשל GitHub Pages), כדי שאפשר יהיה להתקין אותה במסך הבית ולהשתמש בה בלי חיבור לרשת.
אם GitHub Pages מופעל במאגר, הכתובת היא: `https://saramiz2468-rgb.github.io/DESHBORAD/family-cycle/`

באייפון: Safari ← שיתוף ← "הוספה למסך הבית". באנדרואיד: Chrome ← תפריט ← "התקנת אפליקציה".

להרצה מקומית: `python3 -m http.server` בתיקייה הזו (או `npm start`), ואז לפתוח את http://localhost:8000.

## מה יש באפליקציה
- **המשפחה שלי:** כרטיס לכל בת, עם גיל, מחזור אחרון, ימים מאז תחילתו, סטטוס (במחזור / בין מחזורים) ומחזור הבא המשוער.
- **פרופיל בת:** שם, תאריך לידה ותמונה (כולם חוץ מהשם אופציונליים), וצבע כרטיס. אפשר לערוך ולמחוק.
- **מסך אישי:** נתוני המחזור האחרון, ממוצעים, יום במחזור הנוכחי ותחזית.
- **לוח שנה:** ימי מחזור בוורוד, סימון התחלה וסיום, היום מודגש, ימים משוערים במסגרת סגולה. לחיצה על יום מציגה את פרטיו, ומיום ריק אפשר להתחיל מחזור.
- **היסטוריה:** טבלה עם מיון לפי תאריך, עריכה ומחיקה. בטלפון היא מוצגת ככרטיסים.
- **גרפים:** אורך המחזור ומשך הדימום, עם קו ממוצע.
- **נתוני הדגמה:** אפשר לטעון אותם בפתיחה הראשונה או מהתפריט, ולמחוק בלחיצה. הנתונים האמיתיים לא נמחקים איתם.

## חישובים
- **אורך מחזור:** מספר הימים מתחילת מחזור אחד לתחילת המחזור הבא.
- **משך דימום:** מתאריך ההתחלה עד תאריך הסיום, כולל שני התאריכים.
- **ממוצעים:** לפי עד 6 המחזורים האחרונים. מרווח ארוך מ-90 יום נחשב רישום חסר ולא נכנס לממוצע.
- **תחזית:** תחילת המחזור האחרון ועוד אורך המחזור הממוצע, עם טווח סביר. היא מוצגת רק אחרי 3 מחזורים רשומים לפחות, ותמיד מסומנת "הערכה בלבד".
- התאריכים מחושבים כימים שלמים, כך שמעבר לשעון קיץ או חורף לא משבש את הספירה.
- **מניעת כפילויות:** אי אפשר לרשום שני מחזורים שמתחילים באותו יום לאותה בת, או מחזור שחופף למחזור קיים. תאריך עתידי וסיום שקודם להתחלה נדחים. מחזור חדש תמיד נוצר כרשומה חדשה ולא דורס מחזור קודם.

## קבצים
- `calc.js`: חישובי התאריכים והבדיקות
- `store.js`: שמירה במכשיר, הצפנה בקוד, גיבוי ושחזור
- `demo.js`: נתוני הדגמה
- `app.js`, `styles.css`, `index.html`: הממשק
- `manifest.webmanifest`, `sw.js`, `icons/`: התקנה ועבודה בלי רשת
- `test/`: בדיקות אוטומטיות (`npm test`)

> האפליקציה נועדה למעקב אישי ואינה מהווה ייעוץ רפואי. התחזיות הן הערכה בלבד.
