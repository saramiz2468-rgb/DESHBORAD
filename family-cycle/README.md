# המעקב המשפחתי שלי

אפליקציית Web בעברית (RTL) שבה אמא מנהלת מעקב מחזור נפרד לכל אחת מהבנות: פרופילים, לוח שנה, היסטוריה, גרפים ותחזית משוערת.

## הפעלה

נדרש Node.js בגרסה 22.13 ומעלה. אין תלויות להתקנה. מסד הנתונים הוא SQLite המובנה ב-Node.

```bash
cd family-cycle
npm start          # http://127.0.0.1:3000
npm test           # בדיקות חישובים ו-API
```

משתני סביבה (לא חובה):

| משתנה | ברירת מחדל | הסבר |
|---|---|---|
| `PORT` | `3000` | פורט השרת |
| `HOST` | `127.0.0.1` | להאזנה מכל הרשת: `0.0.0.0` |
| `DATA_DIR` | `./data` | תיקיית מסד הנתונים ומפתח ההצפנה |
| `APP_SECRET` | נוצר אוטומטית | מפתח הצפנה ראשי (32 תווים לפחות). אם לא מוגדר, נוצר הקובץ `data/secret.key` |
| `SECURE_COOKIES` | כבוי | `1` כשהאתר מוגש ב-HTTPS (חובה בפריסה ציבורית) |

> **חשוב:** בלי המפתח (`APP_SECRET` או `data/secret.key`) אי אפשר לפענח את הנתונים. גבו אותו יחד עם `data/family-cycle.db`, ואל תעלו אף אחד מהם ל-Git. התיקייה `data/` מוחרגת ב-`.gitignore`.

## מה יש באפליקציה

- **כניסה מאובטחת:** הרשמה וכניסה עם אימייל וסיסמה. כל אמא רואה רק את המשפחה שלה.
- **המשפחה שלי:** כרטיס לכל בת, עם גיל, מחזור אחרון, ימים מאז תחילתו, סטטוס (במחזור / בין מחזורים) ומחזור הבא המשוער.
- **פרופיל בת:** שם, תאריך לידה ותמונה (כולם חוץ מהשם אופציונליים), וצבע כרטיס. אפשר לערוך ולמחוק.
- **מסך אישי:** נתוני המחזור האחרון, ממוצעים, יום במחזור הנוכחי ותחזית.
- **לוח שנה:** ימי מחזור בוורוד, סימון התחלה וסיום, היום מודגש, ימים משוערים במסגרת סגולה. לחיצה על יום מציגה את פרטיו, ומיום ריק אפשר להתחיל מחזור.
- **היסטוריה:** טבלה עם מיון לפי תאריך, עריכה ומחיקה. בטלפון היא מוצגת ככרטיסים.
- **גרפים:** אורך המחזור ומשך הדימום, עם קו ממוצע.
- **נתוני הדגמה:** אפשר לטעון אותם בהרשמה או מהתפריט, ולמחוק בלחיצה. הנתונים האמיתיים לא נמחקים איתם.

## חישובים

- **אורך מחזור:** מספר הימים מתחילת מחזור אחד לתחילת המחזור הבא.
- **משך דימום:** מתאריך ההתחלה עד תאריך הסיום, כולל שני התאריכים.
- **ממוצעים:** לפי עד 6 המחזורים האחרונים. מרווח ארוך מ-90 יום נחשב רישום חסר ולא נכנס לממוצע.
- **תחזית:** תחילת המחזור האחרון ועוד אורך המחזור הממוצע, עם טווח סביר. היא מוצגת רק אחרי 3 מחזורים רשומים לפחות (2 מרווחים), ותמיד מסומנת "הערכה בלבד".
- התאריכים מחושבים כימים שלמים ב-UTC, כך שמעבר לשעון קיץ או חורף לא משבש את הספירה.
- **מניעת כפילויות:** אי אפשר לרשום שני מחזורים שמתחילים באותו יום לאותה בת, או מחזור שחופף לטווח של מחזור קיים. תאריך עתידי וסיום שקודם להתחלה נדחים. הבדיקה רצה גם בדפדפן וגם בשרת.
- מחזור חדש תמיד נוצר כרשומה חדשה ולא דורס מחזור קודם.

## אבטחה ופרטיות

- סיסמאות מגובבות ב-scrypt עם salt. יש הגבלת ניסיונות כניסה (8 ניסיונות כושלים נועלים ל-15 דקות).
- עוגיית התחברות מסוג `HttpOnly` ו-`SameSite=Strict`, ובמסד נשמר רק HMAC של האסימון. בקשות שמשנות נתונים מחייבות כותרת מותאמת ו-Origin תואם (הגנת CSRF).
- **הצפנה במנוחה:** שמות הבנות, תאריכי לידה, תמונות, תאריכי מחזור והערות מוצפנים ב-AES-256-GCM. כל רשומה מוצפנת עם נתונים נלווים (AAD) של המשתמשת והבת, כך שרשומה לא יכולה "לעבור" לפרופיל אחר.
- **הפרדה:** כל שאילתה מסוננת לפי המשתמשת המחוברת, וכל מחזור גם לפי הבת. מסך הכרטיסים מקבל רק תאריכים, בלי הערות.
- כותרות אבטחה: CSP מחמיר (בלי סקריפטים מוטמעים), `X-Frame-Options`, `nosniff`, `no-referrer`.
- מחיקת חשבון מהתפריט מוחקת לצמיתות את כל הנתונים (נדרשת הסיסמה).

בפריסה ציבורית יש להגיש את האתר מאחורי HTTPS (למשל reverse proxy) ולהגדיר `SECURE_COOKIES=1` ו-`APP_SECRET`.

## מבנה הקבצים

- `server.js`: שרת HTTP, ניתוב ה-API, התחברות והרשאות
- `lib/store.js`: מסד הנתונים (SQLite) והצפנת השדות
- `lib/security.js`: הצפנה, גיבוב סיסמאות ואסימונים
- `lib/demo.js`: נתוני הדגמה
- `public/calc.js`: חישובי התאריכים והבדיקות, משותף לשרת ולדפדפן
- `public/app.js`, `public/styles.css`, `public/index.html`: הממשק
- `test/`: בדיקות אוטומטיות (`npm test`)

האפליקציה נועדה למעקב אישי ואינה מהווה ייעוץ רפואי.
