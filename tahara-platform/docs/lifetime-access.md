# גישה לכל החיים – משמעות עסקית ומשפטית

> סטטוס: מסמך תכנון לצורך ניסוח תנאי השירות. **נדרש ייעוץ משפטי** (כולל חוק הגנת הצרכן) לפני פרסום.

## 1. ההגדרה

"גישה לכל החיים" = תשלום חד־פעמי המקנה גישה אישית ל-TAHARA **לכל אורך חיי השירות**, לפי תנאי השירות. אין מנוי, אין חידוש ואין תשלום נוסף על הגישה עצמה.

מומלץ לנסח בתנאים: "לכל משך זמן הפעלת השירות" ולא "לנצח", ולהבהיר זאת גם בדף הרכישה.

## 2. מה זה _לא_ אומר

- אין תפוגה אוטומטית בגלל חלוף זמן – **בשום מקום** במערכת (DB, קוד, cron). ראו `entitlements-and-refunds.md`.
- זה לא מבטיח שכל פיצ'ר עתידי ייכלל ללא תשלום – יש להחליט ולנסח: האם תוספות עתידיות כלולות, או שיכולות להיות מוצרים נפרדים (בלי לפגוע במה שנרכש).
- זה לא מבטיח תמיכה בכל מכשיר/דפדפן לעולם – רק בדפדפנים נתמכים שיפורטו.

## 3. מקרים שיש לטפל בהם בתנאים

| מקרה                                       | הצעת מדיניות                                                                                                                                              |
| ------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **סגירת השירות**                           | הודעה מוקדמת (למשל 90 יום) במייל ובאפליקציה; ייצוא מלא זמין לכל התקופה; שקילת החזר יחסי לרכישות אחרונות (למשל ב-12 החודשים האחרונים) – החלטה עסקית/משפטית |
| **שינוי מהותי בשירות** (צמצום יכולות ליבה) | הודעה מראש; זכות לייצא; שקילת החזר למי שרכשה לאחרונה                                                                                                      |
| **מכירת החברה / העברת השירות**             | התחייבות שהרוכשת תכבד את הזכאויות הקיימות ואת מדיניות הפרטיות, או הודעה + זכות מחיקה                                                                      |
| **הפסקת חשבון בשל הפרת תנאים**             | רק בהליך מתועד (סיבה `tos_violation`), עם הודעה ואפשרות ייצוא                                                                                             |
| **החזר / ביטול עסקה**                      | לפי חוק הגנת הצרכן ומדיניות ההחזרים; מבטל זכאות (ראו `entitlements-and-refunds.md`)                                                                       |
| **Chargeback**                             | הקפאת זכאות עד בירור                                                                                                                                      |
| **פטירת המשתמשת / בקשת קרוב**              | נוהל מחיקה לפי בקשה מאומתת; הזכאות אינה עוברת בירושה                                                                                                      |
| **העברת זכאות לאדם אחר**                   | לא אפשרי (זכאות אישית) – יש לנסח במפורש                                                                                                                   |
| **שינוי מחיר עתידי**                       | לא משפיע על מי שכבר רכשה                                                                                                                                  |

## 4. השלכות עסקיות

- **אין הכנסה חוזרת**: עלויות תפעול (אירוח, DB, מייל, תמיכה) לכל משתמשת נמשכות ללא הגבלה. יש לתמחר בהתאם ולעקוב אחר עלות למשתמשת פעילה.
- **הכרה בהכנסה**: ייתכן שרואה החשבון ידרוש פריסת הכנסה – לבירור.
- **מחויבות טכנית**: תאימות לאחור בייצוא, תחזוקת מנועי חישוב, שמירת נתונים לאורך שנים.

## 5. השלכות טכניות (מיושמות בתכנון)

- `commerce.entitlements` ללא עמודת תוקף.
- שינוי סטטוס רק בפעולה מפורשת ומתועדת.
- ייצוא בפורמט פתוח ומתועד (JSON עם גרסת סכמה), כדי שהנתונים יישארו שמישים גם אם השירות ייסגר.

## 6. החלטות פתוחות לבעלת המוצר

1. נוסח "לכל החיים" המדויק בתנאים ובדף הרכישה.
2. מדיניות החזר יחסי בסגירת שירות.
3. האם עדכונים ופיצ'רים עתידיים כלולים.
4. תקופת הודעה מוקדמת.
